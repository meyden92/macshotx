# sw33tLie/macshot is reference-only, never a code source

The capture-overlay overhaul (2026-08) is modeled on the unrelated, identically named GPLv3 app https://github.com/sw33tLie/macshot. This project is MIT; copying or closely translating any of its code would virally relicense the combined work under GPLv3. We therefore treat it as reference-only: features are specified behaviorally (what the user sees and does) and reimplemented from scratch against those specs — never by porting, transcribing, or paraphrasing its source. If overlay code here ever looks suspiciously similar to theirs, that is convergent AppKit, not lineage; specs and issues under `.scratch/` are the actual provenance. Behavior is not copyrightable, expression is — that line is what keeps the MIT license valid.
